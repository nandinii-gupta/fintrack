# FinTrack – Personal Finance Tracker

FinTrack is a personal finance management web application that helps users track expenses, analyze spending patterns, and manage their finances efficiently.

## 🚀 Live Demo
🔗 https://fintrack-three-beige.vercel.app

## ✨ Features
- Clean and responsive user interface
- User authentication (login & register UI)
- Expense and transaction tracking UI
- Dashboard with financial overview
- Modern UI built with reusable components

## 🛠️ Tech Stack
### Frontend
- React
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB

## 📦 Backend Status
The backend for this project is implemented using Node.js, Express, and MongoDB.  
Due to hosting limitations, the backend is currently configured to run locally and is not deployed yet.

## 🌐 Deployment
- Frontend deployed on **Vercel**
- Backend runs locally during development

## 🧑‍💻 How to Run Locally

### Prerequisites
- Node.js and npm installed
- MongoDB connection configured

### Frontend

```bash
npm install
npm start
```

### Backend

Open a separate terminal and run:

```bash
cd backend
npm install
```
